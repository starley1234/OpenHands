# Генератор PRD

Создавай документ требований к продукту (PRD) для новой функции через интерактивный рабочий процесс с уточняющими вопросами. Используй при планировании функции, старте нового проекта или когда просят создать PRD.

## Триггеры

Этот навык активируется следующими ключевыми словами:

- `создать prd`
- `напиши prd`
- `спланируй эту функцию`
- `требования к`
- `опиши спецификацию`
- `/prd`

## Обзор

Навык PRD проводит через структурированный рабочий процесс:

1. **Уточняющие вопросы** — 3-5 вопросов с вариантами по буквам (отвечай «1A, 2C, 3B» для быстрой итерации)
2. **Структурированный PRD** — генерируется документ с целями, пользовательскими историями, функциональными требованиями, не-целями, метриками успеха и открытыми вопросами
3. **Сохранение** — результат сохраняется в `prd-[имя-функции].md` в корне репозитория

Полные инструкции — в файле [SKILL.md](SKILL.md).
