# Автономный режим (работа без постоянного присутствия)

Этот гайд объясняет, как настроить агента, чтобы он работал **автономно** —
не задавал уточняющих вопросов по мелочам и доводил задачу до конца без
твоего участия.

---

## Зачем это нужно

По умолчанию агент осторожен: может остановиться и спросить пустяк
(«какое имя файла?», «какой размер?», «подтвердите действие»). Это хорошо для
интерактивной работы, но мешает, когда нужно просто дать задачу и уйти.

Автономный режим меняет поведение: агент сам принимает разумные решения,
использует значения по умолчанию и в конце выдаёт отчёт о том, что сделал.

---

## Вариант 1: Автономный агент (рекомендуется)

В репозитории добавлен готовый агент **`autonomous-engineer`**
(файл `openhands-tools/openhands/tools/preset/subagents/autonomous_engineer.md`).

Он:
- **не задаёт** уточняющих вопросов по мелочам;
- принимает разумные значения по умолчанию;
- разбивает задачу на шаги (`task_tracker`) и идёт до конца;
- восстанавливается после ошибок, но не зацикливается (не вызывает один и
  тот же инструмент > 2 раз подряд без изменений);
- в конце выдаёт **итоговый отчёт**: что сделано, какие допущения приняты,
  что осталось, пути к результатам.

### Как использовать

1. Открой Canvas → **Settings → Агент** (страница профилей агентов).
2. Среди доступных агентов выбери **`autonomous-engineer`**.
3. Сделай его активным (`Set as active`).
4. Дай задачу и — при необходимости — отключи **Confirmation mode**
   (Settings → Настройки агента → Подтверждения), чтобы агент не запрашивал
   разрешение на каждое действие.

> Если агент не появился в списке — пересобери образ (см. ниже): субагенты
> из `preset/subagents/` загружаются при старте.

## Вариант 2: Использовать существующего агента, но отключить вопросы

Если не хочешь менять агента — можно снизить количество вопросов:

1. **Отключи Confirmation mode** (Settings → Настройки агента → Подтверждения
   → выключи). Агент перестанет запрашивать подтверждение рискованных действий.
2. **Отключи Security Analyzer** (там же), если не нужен контроль риска.
3. В промпте задачи укажи: *«Работай автономно. Не задавай уточняющих
   вопросов — принимай разумные решения сам. В конце дай краткий отчёт».*

---

## Вариант 3: Через промпт задачи (быстро, без настроек)

Просто допиши к задаче инструкцию автономности, например:

```
Работай автономно и доведи до конца. Не задавай уточняющих вопросов — 
принимай разумные решения и значения по умолчанию. Ограничься 10 шагами.
В конце напиши: что сделано, какие допущения принял, что осталось, 
где результат.
```

---

## Итоговый отчёт агента

В автономном режиме агент в конце выдаёт отчёт:
- **Что сделано** — ключевые изменения/результаты.
- **Допущения** — что решено самостоятельно (значения по умолчанию).
- **Что осталось** — нерешённые вопросы (их должно быть минимум).
- **Пути к результатам** — файлы/URL для просмотра.

Так ты можешь уйти и вернуться к готовому результату, а не отвечать на
вопросы по ходу.

пересобрать образ:

## Советы для устойчивой автономной работы

- **Ограничь итерации**: в настройках агента задай `max_iterations` (например,
  20–30), чтобы задача не крутилась бесконечно.
- **Дай чёткое ТЗ**: чем конкретнее задача, тем меньше агент будет уточнять.
- **Укажи границы**: «не трогай файлы X», «не отправляй данные наружу» —
  чтобы агент не делал лишнего.
- **Используй автоматизации** для регулярных задач (по расписанию/событию) —
  там агент уже работает без твоего присутствия.
