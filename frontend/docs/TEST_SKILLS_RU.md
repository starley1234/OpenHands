# Задание для тестирования русифицированных навыков

После пересборки образа протестируй в Canvas навыки, которые были русифицированы.
Цель — убедиться, что:
1. Навык **активируется** по русскому описанию/триггеру (видно в UI списка навыков).
2. Навык **работает** и даёт результат на русском языке.
3. Ничего **не сломано**: команды, пути, шаблоны вывода сохранены.

> Перед тестом пересобери: `docker compose up -d --build --no-cache`
> и открой Canvas → Skills (страница навыков) — описания должны быть на русском.

---

## Как тестировать

Отправь агенту в новом диалоге **одну из задач ниже** (в тексте задачи должен быть
русский триггер навыка). После каждого прогона скопируй **лог диалога** (текст,
что выдал агент) и пришли мне.

Для каждого навыка оцени по шкале:
- **OK** — навык активировался и корректно выполнил задачу на русском.
- **ПРОБЛЕМА** — навык не активировался, выдал английский текст, или сломался (ошибка).

## Навыки для теста (не требующие ключей)

### 1. `prd` — планирование задач (главный)
```
Создай PRD для функции "тёмная тема" в моём SaaS-приложении. Используй навык prd.
```

### 2. `technical-writing` — техническое письмо
```
Напиши краткое техническое объяснение, как работает кэширование, простым языком. Примени навык technical-writing.
```

### 3. `code-review` — ревью кода
```
Проведи ревью кода этого репозитория (режим /codereview). Оцени качество изменений.
```

### 4. `code-simplifier` — упрощение кода
```
Упрости код в файле <укажи путь>. Используй /simplify.
```

### 5. `iterate` — довести PR до готовности
```
Запусти /iterate для текущего пул-реквеста.
```
*(требует ветки PR и `gh` CLI)*

### 6. `github` — работа с GitHub
```
Покажи информацию о текущем репозитории GitHub (ветки, статус). Используй навык github.
```

### 7. `github-actions` — воркфлоу CI
```
Помоги создать GitHub Actions воркфлоу для CI. Используй навык github-actions.
```

### 8. `agent-memory` — память репозитория
```
Запомни команды сборки этого проекта в AGENTS.md. Используй /remember.
```

### 9. `jupyter` — ноутбуки
```
Покажи структуру Jupyter-ноутбука <укажи путь.ipynb>. Используй навык jupyter.
```

### 10. `docker` — Docker
```
Проверь, установлен ли Docker, и запусти hello-world. Используй навык docker.
```

### 11. `npm` — установка пакетов
```
Установи npm-пакет <пакет> в этом проекте. Используй навык npm.
```

### 12. `uv` — Python-окружение
```
Создай uv-проект и установи зависимости. Используй навык uv.
```

### 13. `deno` — Deno
```
Инициализируй Deno-проект. Используй навык deno.
```

### 14. `frontend-design` — дизайн интерфейса
```
Создай красивую landing page на HTML/CSS. Используй навык frontend-design.
```

### 15. `theme-factory` — темы
```
Примени тему к презентации. Используй навык theme-factory.
```

### 16. `plain-english-content` — простой английский
```
Перепиши этот текст простым английским языком. Используй навык plain-english-content.
```

### 17. `evidence-based-citations` — цитирование
```
Ответь на вопрос с проверяемыми источниками. Используй навык evidence-based-citations.
```

### 18. `learn-from-code-review` — обучение на ревью
```
Проанализируй ревью PR и предложи навыки. Используй /learn-from-reviews.
```

### 19. `add-skill` — добавление навыка
```
Добавь навык codereview из GitHub. Используй /add-skill <url>.
```

### 20. `agent-sdk-builder` — создание агента
```
Помоги спроектировать ИИ-агента на OpenHands SDK. Используй /agent-builder.
```

### 21. `skill-creator` — создание навыка
```
Помоги создать новый навык для моего проекта. Используй skill-creator.
```

## Формат лога для отправки мне

Скопируй текст диалога после выполнения задачи, например:

```
[Задача]: Создай PRD для функции "тёмная тема".
[Результат агента]:
[вставь сюда текст, что выдал агент]
[Оценка]: OK / ПРОБЛЕМА — <что именно>
```

Пришли лог для каждого протестированного навыка. Если какие-то навыки недоступны
(нет ключа, нет ветки PR, нет проекта) — пропусти их и отметь это.
