# Автономное задание для проверки всей системы

Скопируй текст в **один** новый диалог в Canvas как есть (с маркером `[AUTONOMOUS]`).
Агент должен выполнить всё сам, без вопросов. В конце он остановится и пришлёт итоговый отчёт.

---

## Текст задания

```
[AUTONOMOUS]

Выполни следующие шаги строго по порядку и только в рабочей директории проекта (НЕ выходи из неё). В конце каждого шага кратко запиши результат в файл progress.md (создавай или перезаписывай его при необходимости).

ШАГ 1. Создай PRD для новой функции "система напоминаний" для SaaS-приложения. Используй навык prd. Сохрани результат в файл prd-reminders.md.

ШАГ 2. Создай файл hello.py с простой функцией greet(name), которая возвращает "Привет, {name}!", и файл test_hello.py с одним тестом для этой функции. Используй file_editor: создай оба файла, затем исправь/дополни один из них (например, добавь вторую функцию или комментарий), используя str_replace или insert.

ШАГ 3. Перепиши краткое описание проекта в файле README.md простым и понятным языком (2-4 предложения). Используй навык technical-writing.

ШАГ 4. Создай файл tasks.md со списком из 5 конкретных задач по дальнейшей разработке проекта (по одной строке на задачу, с приоритетом).

ШАГ 5. Проверь созданные файлы (выведи их список и первые несколько строк каждого через команды ls и head/cat). Убедись, что файлы реально существуют и содержат ожидаемый текст.

ШАГ 6. Обнови progress.md: запиши итоговый список созданных файлов, что на каждом шаге получилось, и любые ошибки, которые возникали и как ты их исправил.

Когда все шаги выполнены и progress.md обновлён — вызови finish с кратким итоговым отчётом: сколько файлов создано, какие навыки использованы, какие проблемы встретились (если были) и как ты их решил. Не останавливайся раньше, пока все 6 шагов не выполнены.
```

---

## Что это проверяет

| Что | Как проверяется |
|-----|-----------------|
| **Автономный режим** | маркер `[AUTONOMOUS]`, агент сам продолжает между шагами, не задаёт вопросов, доходит до `finish` |
| **file_editor** | создание файлов (`create`), правка (`str_replace`/`insert`), перезапись существующего файла, атомарная запись (включая WSL-фолбек) |
| **Работа с файлами на хосте** | файлы создаются в `/projects/<hex>/` и остаются на хосте (`PROJECTS_PATH`) |
| **Навык `prd`** | ШАГ 1 — планирование, должен отвечать по-русски |
| **Навык `technical-writing`** | ШАГ 3 — должен переписать по-русски/в стиле навыка |
| **Терминал/команды** | ШАГ 5 — `ls`, `head`/`cat` |
| **Самопроверка + отчёт** | ШАГ 6 и финальный `finish` |
