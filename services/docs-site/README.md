# Сервис «docs-site» — документация по репозиторию

Генерирует сайт документации по указанной папке репозитория. Агент читает
README/код/примеры и пишет разделы (`docs/*.md`), прослойка собирает их в
статический сайт на порту **8291**.

## Запуск

```bash
cd services/docs-site
AGENT_SERVER_URL=http://localhost:8000 \
AGENT_SERVER_API_KEY=<api-key> \
node server.mjs
```

Открыть: http://localhost:8291/

В форме укажите **путь на хосте** к папке репозитория (например
`./projects/myapp` или `/home/user/myproject`).

## Пути

- Репозиторий, который надо задокументировать, — папка на хосте. Сервис
  пересчитывает её в путь, видимый бэкенду внутри контейнера
  (`HOST_WORK_ROOT` ↔ `AGENT_WORK_ROOT`, по умолчанию `./projects` ↔ `/projects`).
- Готовые разделы агент пишет в `<рабочая_директория>/docs/`.
- Сайт собирается в `out/index.html`.

## Настройка (config.json)

`scenario.system_prompt` — инструкция агенту (разделы документации),
`project_subdir` — подпапка под рабочую директорию, `max_iterations`.
